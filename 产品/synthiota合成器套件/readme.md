# CircuitPython中的Synthiota合成器套件 – SmallRun

专为CircuitPython设计的合成器，配备27个RGB LED、16个触控板、2个触控滑块、8个电位仪、MIDI输入/输出、高质量16位音频输出以及一个OLED显示屏，由Pico或Pico2驱动。
