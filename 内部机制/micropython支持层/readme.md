# MicroPython支持层

MicroPython为各种硬件提供了一组支持层级别。一层、二层和三层是主要层级，其中一级是最成熟、维护最积极的一级。还有M层用于主要用于维护、开发和测试的其他硬件。下表定义了这些级别。

|                            | 一层 | 二层 | 三层 | M 层 |
| -------------------------- | :--: | :--: | :--: | :--: |
| 在CI下构建                 | ✔︎    | ✔︎    | ✔︎    | ✔︎    |
| 在CI下运行测试（如果可能） | ✔︎    | ✔︎    | ✔︎    | ✔︎    |
| 积极维护                   | ✔︎    | ✔︎    |      | ✔︎    |
| 稳定的Python API           | ✔︎    | ✔︎    |      |      |
| 积极开发新功能             | ✔︎    | ✔︎    |      |      |
| 在硬件上进行了发布测试     | ✔︎    | ✔︎    |      |      |
| 优先级错误报告             | ✔︎    |      |      | ✔︎    |
| 回归需要发布补丁           | ✔︎    |      |      | ✔︎    |
| 具有特定硬件的文档         | ✔︎    |      |      |      |

较低层可能会勾选更多，但上表定义了硬件属于某一层的最低要求。

一层硬件：
- esp32
- mimxrt
- rp2
- samd
- stm32
- unix
- windows

二层硬件：
- alif
- embed
- nrf
- psoc-edge
- renesas-ra
- webassembly
- zephyr

三层硬件：
- cc3200
- esp8266
- pic16bit

M层：
- bare-arm
- minimal
- qemu
